## 1. ¿Qué es este archivo?
Documentación oficial de **LER-Universal v1.3**, la fuente tipográfica y el alfabeto de glifos del ecosistema LER.

## 2. ¿Qué hace?
- Describe la tipografía como representación visual de estados cognitivos.
- Cataloga glifos fundamentales, reflexivos, controles de seguridad y operadores.
- Define nombres, códigos y textos de respaldo (*fallback*).
- Explica usos web, Python/matplotlib e instalación local.
- Remite a una página HTML para verificar el renderizado.

No contiene funciones ni clases ejecutables; el ejemplo de código es ilustrativo.

## 3. ¿Cómo se relaciona con el resto del sistema?
Depende de recursos externos del repositorio:
- `css/ler-universal.css` para uso web.
- `fonts/LER-Universal-v1.3.ttf` para instalación local.
- `examples/test-glifos.html` para validación visual.
- Configuración de `matplotlib.rcParams` para integración Python.

## 4. ¿Es esencial o prescindible?
**Prescindible para la ejecución**, pero **esencial como referencia canónica** del sistema: centraliza la semántica, los códigos y las representizaciones de respaldo. El contenido proporcionado aparece truncado en la tabla de operadores.
